# Provisioning Jinja Teamplate

| | |
| --- | --- |
| Category | FortiManager |
| Trigger Key | `FortiManager Provisioning Jinja Teamplate` |
| Running Playbook | None yet — no trigger key index entry |

## Summary

Creates a Provisioning Jinja template in the FortiManager and assigns it to the device. The template's Jinja is rendered by the FortiManager, not by FortiSOAR.

> The Type value `Provisioning Jinja Teamplate` is spelled as shipped in the picklist.
